# My Workout Tracker

## Project Description

My Workout Tracker is a simple website that helps users keep track of their gym workouts. Users can record exercises, weight, sets, and reps so they can look back at their previous workouts and track their progress.

## Problem

When working out, it can be hard to remember which exercises, weights, sets, and reps were used during previous workouts. This makes it harder to keep track of progress.

## Goal

The goal of this project is to create an easy-to-use workout tracker that allows users to record and review their gym workouts.

## Planned Solution

The application will allow users to create workouts and record information about each exercise. Users will be able to view their workout history and track their progress over time.

## Planned Features

* Create a workout
* Choose a workout type
* Add exercises
* Record weight
* Record sets
* Record reps
* Save workouts
* View previous workouts
* Edit workouts
* Delete workouts
* Track workout progress

## Requirements

1. The user can create a workout.
2. The user can choose a workout type.
3. The user can add exercises to a workout.
4. The user can enter weight, sets, and reps.
5. The user can save a workout.
6. The user can view previous workouts.
7. The user can edit a saved workout.
8. The user can delete a workout.
9. The application keeps workout information organized.
10. The application is available as a published website.
